# إضافة حفظ أرقام حراج في Google Sheets

تضغط الإضافة زر data-testid="post-contact"، ثم تقرأ رقم الجوال من data-testid="contact_mobile"، وتحفظه في الشيت المختار. أسماء الشيتات تُجلب مباشرة من ملف Google Sheets.

## إعداد Google Apps Script

1. افتح https://script.google.com وأنشئ مشروعًا جديدًا.
2. انسخ محتوى apps-script/Code.gs كاملًا إلى المشروع.
3. غيّر SECRET_TOKEN إلى رمز طويل من اختيارك، ولا تغيّر SPREADSHEET_ID.
4. اضغط Deploy ثم New deployment واختر Web app.
5. اجعل Execute as على حسابك وWho has access على Anyone.
6. اضغط Deploy ووافق على الصلاحيات، ثم انسخ رابط Web app المنتهي بـ /exec.

خيار Anyone مطلوب لوصول الإضافة، لكن الكتابة محمية بالرمز. لا تشارك الرابط والرمز.

## تثبيت الإضافة

1. فك ضغط الحزمة.
2. افتح chrome://extensions.
3. فعّل Developer mode واضغط Load unpacked.
4. اختر مجلد haraj-contact-saver نفسه.
5. حدّث صفحة حراج بعد التثبيت.

## الاستخدام

1. افتح الإضافة والصق رابط Apps Script.
2. أدخل نفس SECRET_TOKEN الموجود في Code.gs.
3. اضغط حفظ الاتصال وجلب الشيتات.
4. اختر وايت ماء حائل أو أي شيت آخر.
5. افتح إعلان حراج واضغط اضغط الزر واحفظ الرقم.

يحفظ العمود A للمدينة، وB للرقم بصيغة +966، وC فارغًا للملاحظات، وD لرابط الإعلان. يمنع تكرار الرقم داخل الشيت نفسه.

عند إضافة شيت مدينة جديدة، ضع في الصف الأول: المدينة | الرقم | ملاحظات | التواصل، ثم اضغط جلب الشيتات في الإضافة.
