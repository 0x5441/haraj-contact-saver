# Haraj Contact Saver

إضافة Chrome لحفظ أرقام التواصل من إعلانات حراج مباشرة في Google Sheets.

## المميزات

- الضغط على زر التواصل داخل إعلان حراج
- قراءة رقم الجوال من `href` مباشرة عند ظهور العنصر
- دعم صيغ السعودية الشائعة مثل:
  - `+966555957058`
  - `966555957058`
  - `0555957058`
- توحيد الرقم دائمًا بصيغة `+9665XXXXXXXX`
- حفظ الرقم مع رابط الإعلان في الشيت المحدد
- منع التكرار داخل نفس الشيت
- تشغيل/إيقاف الأداة من popup
- التشغيل التلقائي في الخلفية عند فتح صفحة Haraj أثناء تفعيل الأداة

## النسخة الحالية

- الإصدار: 1.0.3

## متطلبات التشغيل

- Google Chrome
- Google Apps Script
- حساب Google مع إمكانية الوصول إلى Google Sheets

## إعداد Google Apps Script

1. افتح https://script.google.com
2. أنشئ مشروعًا جديدًا
3. انسخ محتوى [apps-script/Code.gs](apps-script/Code.gs) كاملًا إلى المشروع
4. عدّل `SECRET_TOKEN` إلى رمز قوي خاص بك
5. لا تغيّر `SPREADSHEET_ID`
6. اضغط Deploy → New deployment → Web app
7. اختر Execute as: Your account
8. اختر Who has access: Anyone
9. انسخ رابط `/exec` الذي ينتهي بـ `/exec`

> ملاحظة: الرابط العام يحتاج أن يكون متاحًا للجمهور، لكن الوصول للكتابة محمي بـ SECRET_TOKEN.

## تثبيت الإضافة في Chrome

1. افتح `chrome://extensions`
2. فعّل Developer mode
3. اضغط Load unpacked
4. اختر مجلد المشروع نفسه
5. بعد ذلك أعد تحميل الإضافة إذا احتجت

## الاستخدام

1. افتح الإضافة
2. الصق رابط Apps Script
3. أدخل نفس `SECRET_TOKEN` الموجود في Google Apps Script
4. اضغط `حفظ الاتصال وجلب الشيتات`
5. اختر الشيت المطلوب
6. اضغط زر `تشغيل الأداة` إذا رغبت بالتشغيل التلقائي عند فتح صفحات حراج
7. افتح إعلان حراج واسمح للإضافة بجمع الرقم
8. أو استخدم زر `اضغط الزر واحفظ الرقم` يدويًا إذا رغبت

## هيكل المشروع

- `manifest.json` — إعدادات Chrome Extension
- `background.js` — التشغيل في الخلفية والاتصال بـ Apps Script
- `content.js` — اكتشاف رقم الهاتف داخل صفحة حراج
- `popup.html` / `popup.js` / `popup.css` — واجهة الإضافة
- `apps-script/Code.gs` — كود Google Apps Script

## هيكل الشيت في Google Sheets

يُفضّل أن يكون الشكل التالي في الصف الأول:

- العمود A: المدينة
- العمود B: الرقم
- العمود C: ملاحظات
- العمود D: رابط الإعلان

## ملاحظات مهمة

- لا تعدّل `SPREADSHEET_ID` إلا إذا كنت تعرف ما تفعل
- لا تشارك رابط Apps Script أو الرمز الخاص بك مع أحد
- إذا ظهرت رسالة خطأ، تأكد أن رابط النشر منتهي بـ `/exec` وأن الرمز يطابق ما في Apps Script

## الرخصة

هذا المشروع موجه للاستخدام الشخصي والتطوري، مع الاحتفاظ بحقوق المؤلف.
